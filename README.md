# Saudi Airline Complaints Dashboard ✈️

## Project Overview
An interactive dashboard designed to analyze airline complaints in Saudi Arabia and provide insights into airline performance, complaint rates, flight activity, and airport route coverage.

The dashboard helps compare airlines and explore complaint patterns through interactive visualizations and filters.

## Dashboard Features

- **Total Flights:** Displays the total number of flights included in the dataset.
- **Airports Covered:** Shows the number of airports covered.
- **Airline Comparison:** Compares average monthly complaints per 100,000 passengers across airlines.
- **Airline Routes Map:** Visualizes selected airline routes across Saudi Arabia.
- **Departure Time Analysis:** Displays flight departure patterns throughout the day.
- **Interactive Filters:** Allows users to filter the dashboard by airline and month.

## Airlines Included
- flyadeal
- flynas
- Riyadh Air
- Saudia

## Key Insights
The dashboard provides an overview of:
- Differences in complaint rates between airlines.
- Monthly complaint patterns.
- Geographic distribution of airline routes.
- Flight departure trends throughout the day.
